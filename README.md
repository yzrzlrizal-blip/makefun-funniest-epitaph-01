The funniest one-line epitaph: "I finally reached inbox zero. It only took dying." A tiny Python program that writes it to `/output/entry.txt` for make.fun's "Famous Last Words: The Funniest Epitaph" bounty — one line of famous last words, 49 characters, no dependencies, pure standard library.

## Run it

```sh
python3 main.py
```

It writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match.
